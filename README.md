Luciana Carrera, Jennifer Vargas y Lara Zini 
Rediseño de página web Nuestro Amigo Fiel
TP4 C3 DyCV UNLa 1C 2026

Proceso de Desarrollo:
Partiendo de la maqueta digital generada en el TP2 en Figma, trasladamos la información a código (HTML5, CSS) incorporando los nuevos conocimientos de la materia y logrando un sitio web como resultado final.

El sitio cuenta con 5 archivos HTML (/index, /nosotros, /adopta, /comoayudar y /denuncia) y un archivo principal CSS (/estilosg). Además, dentro de los archivos, cuenta con una carpeta de imágenes, una de videos y por último la carpeta swiper que se utiliza para las slides, incorporando Javascript y más CSS en el proyecto.

Dentro del proyecto incorporamos:
Imágenes con slides y animación
Tramas
Video mp4
Favicon
Formulario de contacto completo con distintos tipos de input
Position relative y absolute
Pseudoclases :hover en iconos
Diseño responsive con @media desde 500px
Flexbox en todas las páginas
Jerarquía semántica HTML corregida

Trabajamos de manera colaborativa. Fue sustancial en nuestro proceso de trabajo la función Live Share de Visual Studio, la sincronización conjunta en Github y las videollamadas de consulta. 

El proceso de desarrollo inicialmente tuvo foco en incorporar la información HTML y darle la jerarquía semántica adecuada. En segunda instancia pasamos a incorporar CSS al proyecto, darle Flexbox y trabajar la visualización a partir del Inspector. En última instancia, una vez terminadas todas las versiones mobile, armamos la versión media.

Problemas:
No logramos incorporar @media a la slide de index
Incorporación de Flexbox
Alineación de icono “patita” con la estructura general

Especificaciones:
Tamaño de pantallas 1920x1080px
Editor de código Visual Studio
